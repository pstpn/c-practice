# Тесты для лабораторной работы №08
# 1) Сложение матриц
## Входные данные
Позиционные аргументы app.exe a mtr_1.txt mtr_2.txt res.txt
## Выходные данные
Файл с итоговой матрицей
## Позитивные тесты:
- 01 - Обычное сложение
- 02 - Сложение обычной матрицы с нулевой
- 03 - Результат сложения матрицы - нулевая матрица
- 04 - Сложение матриц из одного элемента
## Негативные тесты:
- 01 - Файл с матрицей не существует
- 02 - Файл с матрицей пустой
- 03 - В файле не числа
- 04 - Некорректные аргументы командной строки
- 05 - Размеры матриц не равны

# 2) Умножение матриц
## Входные данные
Позиционные аргументы app.exe m mtr_1.txt mtr_2.txt res.txt
## Выходные данные
Файл с итоговой матрицей
## Позитивные тесты:
- 01 - Обычное умножение
- 02 - Умножение обычной матрицы на единичную
- 03 - Результат умножения матрицы - нулевая матрица
- 04 - Умножение матрицы из одной строки на матрицу из одного столбца
- 05 - Умножение матриц из одного элемента
- 06 - Результат умножение ненулевых матриц - нулевая матрица
## Негативные тесты:
- 01 - Файл с матрицей не существует
- 02 - Файл с матрицей пустой
- 03 - В файле не числа
- 04 - Некорректные аргументы командной строки
- 05 - Кол-во столбцов первой матрицы не равно кол-ву строк второй

# 3) Поиск определителя методом Гаусса
## Входные данные
Позиционные аргументы app.exe o mtr_1.txt res.txt
## Выходные данные
Файл с определителем
## Позитивные тесты:
- 01 - Нулевая матрица
- 02 - Обычная матрицы
- 03 - Матрицы приведена к верхнетреугольному виду с единичной главной диагональю
- 04 - Матрица из одного элемента
- 05 - Ноль на главной диагонали
- 06 - Нулевой столбец в матрице
- 07 - Нулевая строка в матрице
## Негативные тесты:
- 01 - Файл с матрицей не существует
- 02 - Файл с матрицей пустой
- 03 - В файле не числа
- 04 - Некорректные аргументы командной строки
- 05 - Матрица неквадратная
