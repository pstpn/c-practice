# Тесты для лабораторной работы №07 (задание №1)
## Входные данные
Позиционные аргументы IN_FILE OUT_FILE [f]
## Выходные данные
Файл с отсортированными целыми числами
## Позитивные тесты:
- 01 - Одно число в файле (без фильтра)
- 02 - Числа в файле отсортированы (с фильтром)
- 03 - Числа в файле отсортированы (без фильтра)
- 04 - Все числа нули (без фильтра)
- 05 - Все числа одинаковые (без фильтра)
## Негативные тесты:
- 01 - Файл не существует
- 02 - Файл пустой
- 03 - В файле не числа
- 04 - Некорректные аргументы командной строки
- 05 - В файле одно число (с фильтром)
- 06 - Все числа одинаковые (с фильтром)
- 07 - Все числа нули (с фильтром)
